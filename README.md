# УниПомощник custom

Бот и база данных запускаются через `docker-compose`.  

Для корректной работы необходимо прописать все переменные окружения. Пример есть в файле `.env.example`.  

- Ключ для API Яндекс.Карт можно получить [здесь](https://developer.tech.yandex.ru).  
- Ключ для API OpenWeather можно получить [здесь](https://openweathermap.org/).  
> Важно: регистрация OpenWeather работает только через VPN.  
- Ключ для API курсов валют можно получить на [exchangerate-api.com](https://www.exchangerate-api.com/).  

**Важно при повторном запуске:**  
Если вы запускаете `docker-compose up` повторно, **сначала выполните `docker-compose down`**, чтобы очистить базу данных.  
Дело в том, что Alembic добавляет в БД хэш миграций, но файлы миграций внутри контейнера бота удаляются после остановки. При повторном запуске Alembic не может найти эти файлы, и чтобы избежать ошибок, нужно сначала очистить базу командой `down`.
